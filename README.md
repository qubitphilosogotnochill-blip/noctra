# NOCTRA — Premium Subterranean Luxury Hotel
### Escape the Surface · Western Ghats, Maharashtra, India

NOCTRA is an ultra-luxury subterranean sanctuary carved deep within the 66-million-year-old monolithic Deccan volcanic basalt of Mount Sahyadri, Western Ghats, Maharashtra, India. It combines futuristic brutalist architecture, natural stone formations, subterranean thermal mineral springs, private luxury suites, and silent sanctuaries.

---

## 🏛️ Brand Concept & Architectural Pillars
- **Zero Surface Visibility**: Concealed subterranean funicular descent into the mountain core.
- **Deccan Basalt Integration**: 85% preserved authentic monolithic basalt faces.
- **Circadian Lighting**: Fiber-optic spectrum synchronized with human circadian and melatonin cycles.
- **Passive Geothermal Thermodynamics**: 17.5°C constant natural bedrock temperature.
- **Vedic Silence (Mauna)**: Acoustic isolation rated at 55dB with an anechoic chamber at -2.5dB.

## 🛠️ Technology Stack
- **Framework**: React 19 + TypeScript + Vite
- **Styling**: Tailwind CSS v4
- **Routing**: React Router DOM (v7) with route-level code splitting (`React.lazy`)
- **Animations**: Framer Motion
- **Icons**: Lucide React
- **Design Tokens**: Obsidian Black (`#10100F`), Deep Charcoal (`#191918`), Graphite (`#292825`), Champagne (`#C5AE8B`), Warm Ivory (`#EAE4D9`)
